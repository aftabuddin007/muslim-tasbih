# Prompt

```
Create a Digital Tasbih (Islamic prayer counter) React component with the following exact specifications:

Dhikr list (5 items):

Subhanallah (سُبْحَانَ اللَّهِ) — target 33
Alhamdulillah (الْحَمْدُ لِلَّهِ) — target 33
Allahu Akbar (اللَّهُ أَكْبَرُ) — target 34
La ilaha illallah (لَا إِلَٰهَ إِلَّا اللَّهُ) — target 100
Astaghfirullah (أَسْتَغْفِرُ اللَّهَ) — target 100

Features:

Dhikr selector as pill buttons at the top
Arabic text display card with transliteration and meaning
Large count number (out of target) with golden glow on completion
SVG circular progress ring showing percentage
Large circular tap button (tasbih bead) with ripple animation and press effect
Keyboard support: Spacebar and Enter to count
Reset button and persistent total count display
"Mashallah! Completed!" bounce message on completion
Button disables when target is reached

Design:

Dark navy night-sky gradient background (#0f1b2d to #1a2d4a to #0d2235)
40 randomly placed twinkling star dots
Golden moon circle top-right corner
Glassmorphism dhikr card (rgba(255,255,255,0.05), backdropFilter: blur(12px))
Blue radial-gradient tap button with press/shadow animation
Amber/gold accent colors for highlights
"Ramadan Kareem ✦" header, Arabic footer "رَمَضَان مُبَارَك"
Fonts: Georgia/serif for Latin, Amiri/Georgia/serif for Arabic

Use only React hooks (useState, useEffect, useCallback) and Tailwind utility classes. Single default export named Tasbih.
```
